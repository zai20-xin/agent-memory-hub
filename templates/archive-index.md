# 归档索引（冷库）

> 规则：任何文件归档（移入冷库或确认实体留原处仅作历史参考）必须在下面登记一行：
> `文件/目录 → 内容一句话 → 原位置 → 归档日期`

| 对象 | 内容 | 实体位置 | 归档日期 |
|---|---|---|---|
| （示例）旧 Agent 迁移文档/（N 件） | 某 Agent 停服前的工作区文档全集 | `<归档位置>` | YYYY-MM-DD |
| （示例）profile.md v1（NNKB） | 旧式画像（已被 SSOT 取代） | `<备份位置>` | YYYY-MM-DD |
