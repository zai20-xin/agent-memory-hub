# Agent Registry — 多 Agent 统一治理台账

> 用途：统一管理各 Agent 的记忆位置、接入方式与读写规则。
> 原则：**各 Agent 自治（各自热记忆自己写），中枢只管 SSOT + 协议 + 归档索引 + 审计**。
> 维护时机：新增/停用任一 Agent 时当天更新本表。

## 一、接入矩阵

> 主力格局按实际使用频率确认后填写；频率会变，每季度周检时复核一次。

| Agent | 角色 | 接入方式 | 记忆位置 | 读写规则 |
|---|---|---|---|---|
| agent-a | 主力 + 治理中枢 | 软链接入 | `~/.agent-a/` | 自治；承担周期治理任务 |
| agent-b | 第二主力 | 软链接入 | `~/.agent-b/memory/` | 自治 |
| agent-c | 第三主力 | AGENTS.md 指针 + 软链 | 会话库（自管勿动） | 自治 |
| agent-d | 低频 | 软链接入 | `~/.agent-d/` | 自治 |
| agent-x | 只读监控 | 不接画像 | `~/.agent-x/memories/` | **只读，禁止外部写入** |
| agent-y（已退役） | 封存 | 无 | 原目录 | **只读封存，零写入** |

## 二、共享画像（SSOT）

- 唯一真身：`<hub>/user-profile.md` + 精简版 `user-profile-quick.md`
- 软链接入清单：agent-a / agent-b / agent-d（agent-c 走 AGENTS.md 指针）
- 快版内容裁剪：真身不动时优先更新 quick 版；两边永不允许并存两份真身
